# Migration ledger — camelot_from_youtube → dj-score

Audit 2026-10-21. Rule: copy → repoint → **archive** (amended 2026-10-21 from "delete"). Nothing is purged:
a superseded camelot module, and any outputs it produced, moves to camelot's `archive/` so its artifacts stay
reachable. Tick a row only when the camelot original has left the live tree. "Retire" in the verdicts below
means *archive*, not delete.

**Code only in this repo.** Fixtures, caches and any other generated data stay local (gitignored) and are
regenerated by the scripts that make them. Small, generic test data may be public later; generation is the default.

**Archive layout (decided 2026-10-21):** `camelot_from_youtube/archive/<tool>/` holds the retired script *and* the artifacts it produced. The script stays tracked, since it is already public code. Its artifacts stay gitignored (add `archive/*/*` + `!archive/*/*.py` to camelot's `.gitignore` when the folder is first made). A private repo for the smaller archived files is the likely later home; the archive folder is enough for now. `dynamic/` is untracked in camelot today, so archiving it is a local move.
